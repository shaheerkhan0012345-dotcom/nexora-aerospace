# Nexora Aerospace — Interactive Starfield & Telemetry Tracking 🛸✨

An immersive, front-end aerospace landing page developed in **React 19**, **Vite**, **TypeScript**, and styled with **Tailwind CSS v4**. It features an elegant interactive starfield canvas particles array and a dynamic, scroll-synchronized 3D-angled UFO (scout craft) doing live telemetry calculations and trajectory paths.

---

## 🌌 Tech Stack

- **Framework**: [React 19](https://react.dev/) (Single Page Application)
- **Bundler**: [Vite 6](https://vitejs.dev/) (High-performance build tool)
- **Language**: **TypeScript** (Strict type checking)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (Atomic utility system with CSS-first configuration)
- **Animations & Parallax**: [Framer Motion / Motion](https://motion.dev/) & React state interpolation hooks
- **Icons**: [Lucide React](https://lucide.dev/)

---

## ✨ Features

- **Dynamic Scroll-Synchronized Flying UFO**: The scout craft traces dynamic anchor targets perfectly on scroll, altering hover heights, bank rates, scale factor, and opacities programmatically based on viewport scroll progress.
- **Micro-feathering Alpha Canvas Masking**: Uses a customizable image mask hook converting dark backgrounds into responsive png assets sequentially in the client.
- **Procedural Particle Stars Overlay**: Sections feature a high-performance background starfield rendering beautiful drifting points of light.
- **Modern Responsive Design**: Fluid grids, display typography, and dark space-themed aesthetics optimized for mobile, tablet, and desktop layouts.
